# BMI Calculator

This is a simple **BMI Calculator** application built with **Python** using the **Tkinter** library. It allows users to calculate their Body Mass Index (BMI) based on their weight and height.

## Features

- Input your **name**, **weight**, and **height**.
- Calculate your **BMI** and display the result with a classification (Underweight, Healthy, Overweight, Obese).
- User-friendly interface with error handling for invalid input.

## Requirements

- Python 3.x
- Tkinter (usually comes pre-installed with Python)

## How to Run the App

1. Clone or download this repository.
2. Ensure you have Python 3.x installed on your machine.
3. Run the following command in your terminal/command prompt to launch the BMI calculator:

```bash
python bmi_calculator.py
